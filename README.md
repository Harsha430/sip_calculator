# SIP & Step-Up SIP Calculator

A simple, responsive, and beautiful frontend-only React web application to calculate and visualize SIP (Systematic Investment Plan) and Step-Up SIP investments.

## Features
- Standard SIP Calculator
- Step-Up SIP Calculator (adjusts investment annually)
- Dynamic Data Visualization using Recharts (Pie & Line Charts)
- Yearly breakdown table

## Tech Stack
- React + Vite
- Tailwind CSS v4
- Recharts (Data Visualization)
- Lucide React (Icons)

## Setup & Running Locally

1. Install dependencies:
   ```bash
   npm install
   ```
2. Start the development server:
   ```bash
   npm run dev
   ```

## Deployment
This app is ready to easily deploy on Vercel. 
It includes a `vercel.json` config for rewrite rules, standard OpenGraph metadata, `sitemap.xml`, and `robots.txt` for SEO.
